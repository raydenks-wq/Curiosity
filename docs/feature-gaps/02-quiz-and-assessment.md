# Quiz & Assessment - Gap List

1. Jenis soal masih terbatas; belum mencakup drag-drop, matching, essay advanced.
2. Partial credit dan manual grading flow untuk soal tertentu belum matang.
3. Item analysis (difficulty, discrimination) belum tersedia.
4. Proctoring/anti-cheat quiz tingkat lanjut belum ada.
5. Question bank governance (tagging, taxonomy, reuse policy) belum kuat.
6. Versioning soal dan audit perubahan soal belum rapi.
7. Import/export bank soal standar (QTI/CSV robust) belum lengkap.
8. Retry policy belum fleksibel per cohort/per user exception.
9. Time accommodation (aksesibilitas, tambahan waktu) belum granular.
10. Uji validitas reliability assessment belum terukur.
