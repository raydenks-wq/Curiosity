# Learning Analytics - Gap List

1. Model data analytics masih event sederhana, belum warehouse-ready.
2. Cohort comparison, benchmark, dan segment analytics belum lengkap.
3. Predictive risk model (dropout likelihood) belum tersedia.
4. Drill-down hingga level activity event belum nyaman.
5. Export/report scheduling otomatis belum ada.
6. Data freshness SLA dan delay monitoring belum jelas.
7. Custom dashboard builder untuk instructor/admin belum ada.
8. Attribution learning outcome ke aktivitas spesifik belum matang.
9. Privacy-safe analytics (anonymization policies) belum terdokumentasi.
10. Governance metric dictionary belum tersedia.
