# User & Role Management - Gap List

1. RBAC granular per fitur/aksi masih terbatas.
2. Custom role builder belum ada.
3. SCIM/SSO enterprise integration belum tersedia.
4. Lifecycle automation (joiner/mover/leaver) belum matang.
5. Delegated admin dan scoped administration belum lengkap.
6. Enrollment rule engine per cohort belum fleksibel.
7. Permission audit trail belum detail.
8. Access review/certification periodik belum ada.
9. Impersonation support (secure support mode) belum ada.
10. Session security policy (device trust, step-up auth) belum lengkap.
