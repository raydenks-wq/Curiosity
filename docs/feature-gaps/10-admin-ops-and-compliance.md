# Admin Ops & Compliance - Gap List

1. Centralized observability (logs-metrics-traces) belum production-grade.
2. Incident response runbook dan on-call workflow belum formal.
3. Backup/restore & disaster recovery belum diuji berkala.
4. Data retention dan deletion policy belum lengkap.
5. Privacy compliance pack (consent, DPA, DSAR) belum final.
6. Security hardening checklist (OWASP, secrets, rotation) belum tuntas.
7. Audit evidence collection untuk compliance belum otomatis.
8. SLA/SLO dashboard operasional belum ada.
9. Capacity planning dan cost observability belum matang.
10. Change management/release governance belum terdokumentasi penuh.
